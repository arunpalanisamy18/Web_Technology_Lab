Advanced CSS3 Properties

This webpage demonstrates advanced CSS3 properties including rounded corners, border images, multiple backgrounds, background size, gradients, shadows and pseudo-classes.

Rounded Corners

The border-radius property is used to create rounded corners.

This box uses border-radius.

Border Image

The border-image property allows an image to be used as a border around an element.

Multiple Backgrounds

Multiple background images can be applied to one element using background-image. Their position, repeat and size can also be specified separately.

Gradients and Shadows

CSS3 gradients provide a smooth transition between colors and text shadows provide a shadow effect around text.
